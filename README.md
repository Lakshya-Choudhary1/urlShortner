# 🔗 URL Shortener (MERN + Auth + Google OAuth)

A **production-grade URL shortener** built using the MERN stack with a complete authentication system including **Google OAuth, email-based password reset, and user management**.

---

## 🚀 Live Demo
👉 https://urlshortner-tav4.onrender.com  

---

## ✨ Features

### 🔗 URL Management
- Shorten long URLs instantly  
- Redirect using unique short IDs  
- Enable / Disable URLs  
- Expiry support for links  
- Track usage (analytics-ready)  

### 🔐 Authentication & Security
- Email & Password Authentication  
- Google OAuth Login  
- Forgot Password (Email-based)  
- Reset Password via secure token  
- Protected routes (frontend + backend)  

### 📧 Email Services
- Password reset email system  
- Token-based secure links  
- Expiry-based reset handling
